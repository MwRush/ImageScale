# Image Scale

Outil web pour redimensionner des images avec conservation des détails.

## Fonctionnalités

- Redimensionnement par facteur d'échelle (x1 à x10)
- Upscale pixel-perfect (nearest neighbor)
- Contrôle de l'intensité de perte de qualité (irréversible)
- Téléchargement PNG
- Mode sombre/clair
- Interface FR/EN
- Design responsive

## Utilisation

1. Sélectionner une image
2. Définir le facteur d'échelle
3. Ajuster l'intensité de perte si nécessaire
4. Télécharger le résultat

# Image Scale

Web tool to resize images with detail preservation.

## Features

- Scaling by factor (x1 to x10)
- Pixel-perfect upscale (nearest neighbor)
- Quality loss intensity control (irreversible)
- PNG download
- Dark/light mode
- FR/EN interface
- Responsive design

## Usage

1. Select an image
2. Define scale factor
3. Adjust loss intensity if needed
4. Download result
